# 输出模板｜Teacher Science Brief HTML

当用户说“图文并茂 / HTML / 老师一眼看懂”时，可生成完整单页 HTML。

## 必须区分

### 区块 A｜给老师看的科学底座
- 现象事实
- 成人版解释
- 通俗类比（标注类比）
- 可能变量
- 目前未知

### 区块 B｜儿童发展视角
- 对当前年龄可直接感知什么
- 真正有挑战的经验
- 哪些过于抽象
- 候选朴素理解（标“可能，不是事实”）

### 区块 C｜探究价值筛选
用 A / B / C：
- A 值得追
- B 先观察
- C 教师诊断即可

### 区块 D｜如果教师选定方向
才展示问题树或下一步观察。

## 视觉

- 柔和低饱和；
- 投屏优先；
- 不做“专家审查报告”；
- 不用大红叉；
- 不把科学不确定性隐去；
- 页面顶部提示：

> 先把老师讲明白，再决定什么值得交给儿童。
