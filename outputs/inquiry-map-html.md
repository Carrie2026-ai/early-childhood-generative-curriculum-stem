# 输出模板｜课程探究一页图 HTML

当用户明确提出“生成展示版 / 一页图 / 可视化 / 汇报版”时，用以下规范输出**完整可运行 HTML**。

## 必须包含

1. 顶部：当前课程一句话结论；
2. 左上：儿童事实 / 教师推断 / 教师预设三类卡片；
3. 中部：问题树（纯 CSS + 嵌套列表即可，不依赖外部库）；
4. 右侧：科学 / 工程判断与 STEM 自然发生点；
5. 下部：下一步观察卡；
6. 底部：教师支架、先别急着、风险提醒；
7. 若有古诗词，单独一块“诗词是否适合进入”，注明 A / B / C 级与进入方式。

## 视觉要求

- 白底、克制、适合幼儿园教研场景；
- 内容宽度 1100—1280px，投影优先；
- 标题层级明确；
- 关键结论用色块 / 边框强调，但不要满屏高饱和颜色；
- 单卡片文字尽量不超过 6 行；
- 手机端自动单列；
- 打印时去掉阴影并保持边框；
- 不引用外部字体、CSS 或 JS；
- 不生成装饰性无意义图表。

## 数据图表

若输入包含真实测量数据，可在 HTML 中用简单 SVG / CSS 条形图展示。不得创造数值。

## 页面顶部固定提示

> AI 帮助展开可能性，教师依据真实儿童证据做最终判断。
