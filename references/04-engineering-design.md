# 04｜幼儿工程设计规则

## 核心区别

科学更多指向解释现象，工程更多指向解决真实需要。

幼儿工程不等于复杂制造。儿童围绕真实问题经历方案形成、表征 / 制作、测试和改进，就可能出现工程思维萌芽。

## 工程问题五要素

1. **真实需要 / 问题**：到底要解决什么？
2. **成功标准**：怎样算“能用 / 更好”？
3. **限制条件**：材料、时间、空间、安全、尺寸、儿童能力等。
4. **多个可能方案**：不能只有教师预先确定的唯一做法。
5. **测试与改进**：作品需经过使用或测试，根据结果再调整。

## 推荐循环

**发现需要 → 明确问题 → 想办法 → 画 / 说 / 搭模型 → 制作 → 测试 → 比较 → 修改 → 再测试**

允许跳跃与往返，不把它教成僵硬步骤。

## 设计是否真实

儿童的图画 / 计划只有在后续制作中被参考、修改或讨论，才真正发挥设计作用。若画完即丢、全体仍按教师范例制作，则“设计”容易流于形式。

## 科学与数学如何进入

只在解决工程问题时自然调用：

- 科学：材料属性、力、光、声音、水、空气等可观察规律；
- 数学：长度、数量、大小、形状、排序、比较、简单数据；
- 技术：儿童真实使用的工具、材料加工方式和程序性做法；
- 工程：围绕需要设计、测试与改进。

不要求每个项目 S/T/E/M 四项齐全。

## 失败规则

失败首先是数据：

- 哪里没达到标准？
- 儿童怎么解释？
- 哪个条件可能有关？
- 下一轮只改什么？
- 怎样判断改后更好？

AI 不直接给“正确改法”，除非涉及安全。
