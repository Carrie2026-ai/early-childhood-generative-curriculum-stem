# 专业参考来源与提炼说明

本文件说明 Skill 的专业知识底座。正式论文、出版物或公开课程中如需引用，应回到原始文献核对并按规范引用。

## 中国学前教育政策与专业框架

1. 教育部：《3—6岁儿童学习与发展指南》及相关解读。吸收要点：科学学习重在探究兴趣、探究过程和初步探究能力；幼儿通过直接感知、实际操作和亲身体验获得经验。
2. 教育部：《幼儿园教育指导纲要（试行）》。吸收要点：利用身边事物和现象支持科学探索；文学体验重视优秀作品、语言美感与多种方式体验。
3. 学前教育质量评估与园本实践相关政策。吸收要点：从真实儿童和真实班级出发，避免机械照搬、形式化特色与结果导向。

## 国内 STEM / 科学教育

4. 张俊及相关幼儿科学教育 / 早期 STEM 研究与专业著作。吸收要点：真实问题、儿童主动探究、工程设计、制作测试与改进，科学 / 数学经验在解决问题中自然进入。
5. 国内幼儿园 STEM 实践研究。吸收要点：以真实问题为内容、以工程设计为架构，重视设计—制作—测试—优化。

## 国际早期科学与工程教育

6. NAEYC：幼儿工程设计相关资源。吸收要点：Ask / Imagine / Plan / Create / Improve 等幼儿化工程循环，重视多种方案、制作测试和改进。
7. NGSS：K–2 Engineering Design。吸收要点：定义简单问题、发展多个可能方案、测试比较并根据结果改进。
8. NSTA：Early Years / Ongoing Inquiry 相关资源。吸收要点：持续性探究应与儿童经验和兴趣相关，并允许儿童通过行动和调查获得答案。
9. STEMIE：Early Childhood STEM / Engineering 资源。吸收要点：幼儿在日常游戏中识别问题、探索材料、形成和改进方案；教师通过开放性问题和材料支架延伸思考。

## 古诗词 / 文学启蒙

10. 教育部学前语言与艺术领域相关要求。吸收要点：幼儿文学学习重在接触优秀作品、感受语言丰富与优美，通过直接经验、声音、动作、画面和多种活动深化体验，避免超龄知识灌输。

## 使用原则

- 本 Skill 对公开专业思想做的是原创规则化提炼，不复制第三方长段文字。
- 文献名称用于说明专业来源，不代表原作者对本 Skill 的背书。
