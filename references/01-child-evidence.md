# 01｜儿童证据与教师判断

## 三类信息

### 儿童事实
可直接观察、记录、回看的信息：儿童原话、行为、作品、动作、操作顺序、重复关注、测试结果、冲突与失败。

### 教师推断
教师对事实的解释，例如“他很感兴趣”“她已经理解”“他们想研究……”。推断可以有价值，但必须与事实分开。

### 教师预设
课程主题、成人目标、计划安排、希望引导的知识与结果。

## 可执行规则

1. 优先问“你看见了什么”，再问“你怎么理解”。
2. “喜欢 / 感兴趣 / 懂了 / 会了”若没有行为证据，标记为待核实。
3. 一次偶发行为不自动升级为长期课程线索。
4. 持续性可从反复提问、重复尝试、主动回到同一问题、持续讨论等证据判断。
5. 儿童出现新证据后，允许推翻教师原来的判断。
6. 多个儿童存在不同反应时，不强行归并成统一兴趣。
7. 不为了漂亮的课程故事把现场整理得过度顺滑。
