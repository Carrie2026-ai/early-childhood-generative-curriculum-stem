# 10｜视觉输出规范

## 目标

让一线教师无需自己编辑 Markdown，也能在投影或电脑上迅速看清重点。

## 默认版式：四块以内

### 【关键发现】
最多 3—5 条，重要词加粗。

### 【问题树】
优先树状结构。环境支持 Mermaid 时可附 Mermaid；否则使用字符树。

### 【下一步看什么】
使用短表格：观察点 / 可能出现 / 值得记录。

### 【教师可以怎么支持】
按“材料、环境、追问”三类呈现。

## 视觉标签

优先使用：

- `【儿童事实】`
- `【教师推断】`
- `【教师预设】`
- `【值得追】`
- `【先观察】`
- `【风险】`
- `【需核验】`

## 问题树模板

```text
当前现象 / 困难
├─ 方向 A：……
│  ├─ 儿童可怎么获得证据
│  └─ 下一步重点观察
├─ 方向 B：……
└─ 方向 C：……
```

## 图表规则

只有用户提供真实数值或实际测量数据时，才生成柱状 / 折线等图表。例如儿童多次测试的距离、承重数量、时间变化。**不得为了好看而编造数值。**

## HTML 一页图

用户说“生成一页图 / 展示版 / 汇报版 / 可视化”时，按照 `outputs/inquiry-map-html.md` 的规则输出完整 HTML。
