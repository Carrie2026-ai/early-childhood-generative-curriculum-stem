# 13｜Inquiry Value Gate：科学上能试，不等于儿童值得试

## 为什么需要这一关

AI 很容易把“变量可控制、结果可观察”误认为“适合幼儿探究”。

真正的课程问题还需要教育价值判断。

## 五项判断

### 1. 儿童来源
是否来自儿童真实问题、失败、反复关注、同伴分歧或当前工程需要？

### 2. 认知 / 设计张力
探究前后，儿童是否可能获得新的关系理解、证据意识或方案改进？

### 3. 可行动
儿童能否通过自己的行动获得证据，而不是主要靠成人讲解？

### 4. 发展适宜
对当前儿童来说：
- 不只是已经熟悉的日常常识；
- 也不是必须依赖成人抽象知识才能理解。

### 5. 生成潜力
结果能否自然带出新问题、解释变化或工程改进，而不是做完即结束？

## A / B / C 判定

### A｜值得继续追
儿童证据明确，挑战适中，可获得新证据，课程价值清楚。

### B｜先观察
方向可能有价值，但儿童证据不足。先观察儿童是否真的提出、反复操作或出现认知冲突。

### C｜教师理解 / 诊断即可
出现以下任一情况时优先 C：
- 只是教师排查系统原因；
- 与儿童当前问题无关；
- 结果过于显而易见且没有新的关系理解；
- 过于抽象，儿童只能听成人解释；
- 需要大量成人操作；
- 只是为了展示“控制变量”；
- 会把原本更有价值的真实工程问题带偏。

## 重要细节

“成人觉得显而易见”不能单独作为否定理由。

关键是：
> **有没有儿童真实证据表明这里存在困惑、冲突或持续兴趣？**

如果没有，AI 不应主动假设“孩子肯定不知道”。
