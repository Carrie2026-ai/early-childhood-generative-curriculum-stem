# 合成案例 02｜怎样让玩具车安全跨过“沟”？

> 本案例为独立合成，不来自任何合作园所真实课程。

## 场景

大班建构区里，两张矮桌之间留有约 20 厘米空隙。儿童把它想象成“山沟”，玩具车每次开到边缘都会掉下去。有幼儿说：“我们要修一座桥。”

## 工程判断

### 真实需要
让玩具车能从一边稳定开到另一边。

### 可能成功标准
- 车能通过；
- 桥不塌；
- 桥面不会明显滑动。

### 约束
- 只能使用建构区现有纸板、木片、积木、夹子和绳；
- 不使用成人电动工具；
- 儿童需能自己调整。

## 问题树

```text
怎样让车安全过沟？
├─ 桥面怎样才不会弯？
├─ 桥怎样固定才不滑？
├─ 要不要桥墩？放哪里？
└─ 不同材料哪种更适合？
```

## 测试与改进

让车实际通过，比较不同方案在稳定、承重和易搭建上的表现，而不是由教师主观宣布“成功”。
