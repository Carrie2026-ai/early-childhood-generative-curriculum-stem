# 合成案例 01｜松果为什么有时张开、有时合起来？

> 本案例为独立合成，不来自任何合作园所真实课程。

## 场景

秋天散步后，中班把松果放在自然角。两天后，有幼儿发现：“昨天这个是张开的，今天怎么合起来了？”另一个幼儿把松果拿到窗边说：“是不是晒太阳就会开？”随后几名幼儿反复比较不同松果。

## Skill 应识别

### 【儿童事实】
- 儿童注意到同一类物体外形发生变化；
- 儿童提出“晒太阳”的猜测；
- 有多人主动反复比较。

### 【值得追】
这是一个可由儿童通过观察、比较和改变环境条件获得证据的科学问题。

## 问题树示例

```text
松果为什么会张开 / 合起来？
├─ 和干 / 湿有关吗？
│  ├─ 放在干燥处
│  └─ 放在潮湿处
├─ 和温度有关吗？
└─ 不同松果变化一样吗？
```

## 下一步观察

- 儿童是否会主动比较同一个松果前后变化；
- 是否能想到记录；
- 当结果与猜测不同，儿童是否愿意修改解释。

## 不宜提前

不要先告诉完整科学原理，再安排儿童验证。
