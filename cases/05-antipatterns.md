# 合成反例库｜让 Skill 学会说“不”

> 以下均为独立合成。

## 反例 A｜“秋天 STEM 大拼盘”

教师输入：
> 本周主题是秋天，请设计一个 STEM 活动，要包含科学、技术、工程和数学。

### Skill 不应
直接输出：认识树叶 / 数树叶 / 做树叶房子 / 看树叶视频。

### Skill 应
先追问：最近孩子在秋天相关活动中，真实出现过什么持续问题或反复行动？如果没有，先从儿童经验中寻找问题，不急着凑 STEM。

---

## 反例 B｜统一范例“小风车”

教师已经准备好同一尺寸、同一裁切线，让所有儿童照步骤做风车，并计划称为“工程设计”。

### 诊断
制作存在，但方案空间、成功标准、测试改进都很弱，更接近指导性手工。

### 可转化方向
如果儿童真实遇到“为什么有的转得快 / 怎么让它在更小的风里也能转”等问题，再可能进入科学探究或工程改进。

---

## 反例 C｜古诗硬贴科学

儿童正在比较不同材料吸水速度。教师希望最后加入一首与当前经验连接很弱的古诗，只为了体现传统文化。

### Skill 应
明确指出连接距离过远，不建议为了“融合”强行加入。继续把当前探究做深更自然。
