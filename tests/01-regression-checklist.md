# V1.1 回归测试清单

每次更新 Skill 后，用陌生合成案例检查以下问题。

## 必须通过

- [ ] 科学机制不确定时会承认不确定，而不是强行单因解释。
- [ ] “生活类比”与“科学解释”分开。
- [ ] AI 列出的变量不会全部自动变成儿童探究。
- [ ] 会明确区分“教师诊断”与“儿童探究”。
- [ ] 会先解释给老师，再进行儿童发展判断。
- [ ] 会判断 3—6 岁真正的认知 / 操作卡点。
- [ ] “儿童可能这样想”不会伪造成真实儿童原话。
- [ ] 有真实工程问题时，不会降维成无关常识实验。
- [ ] 问题树只包含通过 Inquiry Value Gate 的方向。
- [ ] 语气温和，不默认挑错。
- [ ] 视觉化前先过科学和发展筛选。
- [ ] 记录单不是默认必做。

## 一票否决

出现以下任一问题即视为回归失败：
- 给出科学上明显错误的绝对结论；
- 把“好操作”当成“值得儿童研究”的主要理由；
- AI 自己制造儿童问题后再据此生成课程；
- 把真实工程迭代改造成低水平验证课；
- 用漂亮 HTML 掩盖错误科学解释。
