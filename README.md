# 幼儿园生成课程与 STEM 探究导航 Skill｜V1.1

面向 3—6 岁幼儿园教师的**科学理解、儿童发展判断、生成课程与 STEM 探究辅助 Skill**。

## V1.1 最重要的改变

旧版本容易从：
> “发现一个现象” → “列变量” → “生成儿童探究”

直接往下走。

V1.1 改成：

> **儿童节点 → 先把老师讲明白 → 看 3—6 岁儿童真正的卡点 → 探究价值筛选 → 教师选择 → 才生成问题树 / 课程推进**

新增四个核心底座：

1. `11-teacher-science-brief.md`：教师先理解科学机制与不确定性；
2. `12-developmental-science-map.md`：3—6 岁科学经验与发展卡点；
3. `13-inquiry-value-gate.md`：科学上可测 ≠ 儿童值得探究；
4. `14-teacher-diagnostic-vs-child-inquiry.md`：教师诊断变量 ≠ 儿童课程。

## 它现在重点解决

- 老师自己对科学原理拿不准；
- AI 为了通俗把科学讲错；
- 变量很多，但不知道哪些值得给儿童；
- AI 自己制造“孩子可能会问”的问题；
- STEM 课程变成学科拼盘；
- 工程项目被降维成简单科学验证；
- 记录单、跨学科和视觉化形式大于内容。

## 默认关系

**AI 先帮教师把可能性和科学底座弄清楚，教师再决定什么值得交给真实儿童。**

## 隐私与案例

公共包全部使用独立合成案例，不写入合作园所或用户附件中的真实课程材料。
