# 幼儿园生成课程与 STEM 探究导航 Skill｜V1.0

面向 3—6 岁幼儿园教师的课程生成、科学探究与工程设计辅助 Skill。

## 它解决什么

它不替教师“一键生成完整主题课程”，而是帮助教师从真实儿童材料出发：

1. 区分儿童事实、教师推断与教师预设；
2. 找到值得继续追随的课程生成点；
3. 展开问题链 / 问题树与多种探究可能；
4. 区分科学探究问题与工程设计问题；
5. 提示下一步重点观察什么、可能出现什么、教师可如何支持；
6. 在需要时判断古诗词能否自然进入，并进行年龄适宜性筛选；
7. 用适合一线教师阅读和投影展示的方式呈现结果。

## 目录

- `SKILL.md`：核心运行规则与多轮对话流程
- `references/`：专业判断底座
- `cases/`：独立合成案例与反例
- `outputs/`：问题树、观察卡、一页图等视觉输出规范
- `COPYRIGHT.md`：版权声明
- `LICENSE-NONCOMMERCIAL.md`：非商用教育使用许可
- `CHANGELOG.md`：版本记录

## 案例与隐私说明

本包中的案例均为独立合成案例，用于展示判断逻辑；不包含任何合作园所、培训对象、用户附件或真实园本课程的原文、结构复刻及可识别信息。

用户在实际使用时上传的园所资料，只作为当次分析输入，不应写回公共案例库。
